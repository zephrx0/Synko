# Synko 2.4.3

- Тихий автозапуск явно запускает Synko в трее без открытия окна
- Режим запуска учитывается при восстановлении приложения средствами Windows
- Изменение «Тихого запуска» сразу обновляет команды автозапуска и восстановления
- Старые записи автозапуска обновляются автоматически, настройки сохраняются

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe** либо обновитесь в настройках Synko. Для запуска в трее включите «Запускать вместе с Windows» и «Тихий запуск».

---

Fixes quiet Windows startup and restart registration. Changing the quiet-startup preference immediately updates both launch commands. Existing startup entries are migrated automatically.
