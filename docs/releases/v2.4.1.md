# Synko 2.4.1

- Добавлен «Тихий запуск» в настройках автозапуска, включён по умолчанию
- При входе в Windows Synko запускается в трее без открытия окна
- Повторный фоновый запуск больше не открывает окно уже работающего приложения
- Обычный запуск через ярлык открывает интерфейс; настройки автозапуска сохраняются

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe** либо используйте **Synko-2.4.1-win-x64.exe**.

---

Quiet startup is enabled by default. Synko starts in the tray when signing into Windows. Repeated background launches keep the window hidden; opening the app manually shows its interface.
