# Synko 2.2.1

Исправлено долгое ожидание обложек Apple Music и YouTube.

Исправлен некорректный MIME-тип нативных картинок Apple Music: полученная обложка больше не превращается в неоткрываемый data URL.

- Нативная картинка Windows отображается сразу, без ожидания каталога Apple и ответа Discord
- После сбоя загрузка картинки повторяется для того же трека
- Сетевая ошибка больше не блокирует поиск на 2–3 минуты; серверный Retry-After соблюдается
- Найденные ссылки и загруженные картинки сохраняются локально между запусками
- Обложка альбома используется для других треков того же исполнителя и альбома без повторного поиска
- Поиск включает исполнителя, переход на другой трек отменяет старую загрузку

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe**. Для обновления также доступен отдельный **Synko-2.2.1-win-x64.exe**. Настройки сохраняются.

Windows 10/11 x64, Microsoft Edge WebView2 Runtime. .NET включён в сборку.

---

Fixes delayed artwork: Windows thumbnails appear immediately, failed downloads retry without changing tracks, and catalogue/image caches survive restarts. Catalogue searches include the artist and transient failures no longer suppress artwork for minutes. Apple server retry limits are respected.
