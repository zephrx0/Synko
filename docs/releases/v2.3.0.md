# Synko 2.3

- Статусы Apple Music и браузеров расположены в двух колонках по краям окна
- Плашки полупрозрачные и принимают цвет текущей темы и обложки
- Название источника отделено от состояния «играет» / «пауза»
- Статусы остаются информационными элементами без наведения, нажатия и фокуса
- Убраны лишние маркеры на шкале времени, края волны стали плавными
- Сохранены быстрые обложки, повторные загрузки и локальный кэш из 2.2.1

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe**. Отдельный **Synko-2.3.0-win-x64.exe** доступен для портативного запуска и встроенного обновления.

Windows 10/11 x64, Microsoft Edge WebView2 Runtime. .NET включён, настройки сохраняются.

---

Translucent source status labels now sit in two columns, follow the app theme and separate the source name from its playback state. They remain informational, without button interactions. The playback timeline has smooth wave edges and no extra markers. Fast artwork and persistent caching from 2.2.1 are retained.

Download **Synko-win-x64.zip**, extract and run **Synko.exe**, or use the versioned executable. Existing settings are preserved.
