# Synko 2.4.2

- Исправлен поиск обложек для Discord: добавлен резервный каталог, если основной недоступен или не находит альбом
- Обложки повторно запрашиваются на текущем треке после временного сбоя
- Быстрое переключение треков больше не запускает лишний поиск для каждого пропущенного трека
- Добавлен кэш обложек альбомов из резервного каталога
- Helium распознаётся как браузер в режиме «Авто», включая статус YouTube и превью видео
- Улучшено чтение адреса YouTube в браузерах с переименованной адресной строкой

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe** либо используйте **Synko-2.4.2-win-x64.exe**. Также можно обновиться в настройках Synko.

---

Fixes Discord artwork lookup with a fallback catalogue, automatic retries and an album cache. Rapid track skips cancel unnecessary lookups. Adds Helium browser detection, YouTube thumbnails and improved address-bar support.
