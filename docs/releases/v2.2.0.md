# Synko 2.2.0

Музыка Apple Music и видео из браузера в профиле Discord. Первый публичный релиз для Windows 10/11 x64.

## Установка

Скачайте **Synko-win-x64.zip**, распакуйте в постоянную папку и запустите **Synko.exe**. Отдельная установка .NET не нужна. Требуется Microsoft Edge WebView2 Runtime.

В мастере укажите Application ID из [Discord Developer Portal](https://discord.com/developers/applications), выберите «Авто» и включите публикацию. Токен бота и Client Secret не нужны.

## Возможности

- Apple Music и браузеры через медиасессии Windows
- YouTube-статус, обложки, превью и ссылка на текущий ролик
- Исправленный выбор браузера, когда Apple Music остаётся на паузе
- Иконки 15 распознаваемых браузеров
- Новый интерфейс, светлая и тёмная темы, цвет из обложки и волнистый прогресс
- Работа в трее, автозапуск и встроенное обновление с проверкой SHA-256
- Автономный exe около 55 МиБ, ZIP около 49 МиБ

Для ссылки и превью YouTube в Discord нужен URL ролика: если Synko запущен при уже фоновой вкладке, откройте её один раз. В обычном режиме приложение не переключает вкладки и не читает историю браузера.

27 групп проверок Core, проверки Windows и готового интерфейса прошли. На настоящем Discord проверены YouTube-статус, превью и снятие активности. Остальные браузеры проверены по идентификации и загрузке иконок; отдельный ручной прогон каждого браузера не выполнялся.
