# Synko 2.4.5

- Firefox распознаётся по системному идентификатору установки, вместо строки с цифрами отображается браузер
- Улучшено получение адреса YouTube в Firefox, Helium и Chrome без расширений
- Исправлено различение Helium и Chrome, когда оба браузера открыты одновременно
- Зависший запрос к браузеру больше не блокирует получение превью
- Несколько браузеров получают превью по очереди без зависания на одном источнике
- Последнее распознанное видео восстанавливается после перезапуска Synko, даже если вкладка уже в фоне
- Добавлена повторная отправка публичной обложки, если Discord принял активность без изображения
- Исправлен логотип Helium в тёмной теме

Обновитесь в настройках Synko либо скачайте **Synko-win-x64.zip**. Если браузер не отдаёт адрес фоновой вкладки, откройте её один раз для получения превью в Discord.

---

Fixes Firefox installation-ID detection, YouTube URL capture and Helium/Chrome identification. Browser lookups are isolated and time-limited. Adds retries for images omitted from Discord acknowledgements and fixes the Helium icon in dark mode. No browser extension is required.
