# Synko 2.4

Добавлена интеграция с настольным Spotify для Windows, включая версию Microsoft Store.

- Статус «Слушает Spotify» в Discord с треком, исполнителем, альбомом и временем
- Spotify в режиме «Авто» и отдельный выбор Spotify в настройках и мастере
- Обложка из медиапанели Windows отображается сразу; для Discord публичная картинка ищется в каталоге Apple с общим кэшем
- Отдельная иконка Spotify и резервная картинка, кнопка «Найти в Spotify»
- Снятие активности на паузе и при отключении публикации
- Режимы источника в настройках размещены в сетке 2×2

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe** либо используйте **Synko-2.4.0-win-x64.exe**. Windows 10/11 x64, WebView2 Runtime; .NET включён. Настройки сохраняются.

---

Adds Spotify desktop/Store detection, Listening to Spotify presence, source selection, artwork, a Spotify search button and a dedicated icon. Windows thumbnails appear immediately; public Discord artwork is matched in the Apple catalogue.
