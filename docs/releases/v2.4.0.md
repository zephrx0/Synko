# Synko 2.4

Добавлена интеграция с настольным Spotify для Windows, включая версию Microsoft Store.

- Статус «Слушает Spotify» в Discord с треком, исполнителем, альбомом и временем
- Spotify в режиме «Авто» и отдельный выбор Spotify в настройках и мастере
- Обложка из медиапанели Windows отображается сразу; для Discord публичная картинка ищется в каталоге Apple с общим кэшем
- Отдельная иконка Spotify и резервная картинка, кнопка «Найти в Spotify»
- Снятие активности на паузе и при отключении публикации
- Режимы источника в настройках размещены в сетке 2×2

Spotify-аккаунт и дополнительные ключи в Synko не требуются. Существующий Discord Application ID подходит. Для получения воспроизведения нужен настольный Spotify, передающий медиасессию Windows.

Проверено: 35 групп Core, 7 групп Windows, интерфейс на 100%/150% DPI. Настоящий Discord подтвердил Spotify-статус и обложку с тестовыми данными. Настоящий клиент Spotify на проверочной машине не установлен, его фактическое воспроизведение не проверено.

Скачайте **Synko-win-x64.zip**, распакуйте и запустите **Synko.exe** либо используйте **Synko-2.4.0-win-x64.exe**. Windows 10/11 x64, WebView2 Runtime; .NET включён. Настройки сохраняются.

---

Adds Spotify desktop/Store detection, Listening to Spotify presence, source selection, artwork, a Spotify search button and a dedicated icon. No Spotify sign-in or developer keys are required. Windows thumbnails appear immediately; public Discord artwork is matched in the Apple catalogue.

Verified with simulated Spotify media, unit/Windows/UI checks and a real Discord RPC acknowledgement. The actual Spotify application was not installed for end-to-end playback testing.
